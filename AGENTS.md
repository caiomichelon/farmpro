# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v57.0.0/ before writing any code.

O projeto está na SDK 57 (atualizado em set/2026 — a Apple finalmente aprovou a versão mais nova do
Expo Go, que tinha ficado travada na SDK 54 por meses; ver histórico em
https://expo.dev/changelog/expo-go-and-app-store-may-2026). Antes de rebaixar a SDK de novo por
qualquer motivo, cheque se o Expo Go da App Store realmente exige isso — senão o app fica
incompatível com o Expo Go de quem já atualizou.
