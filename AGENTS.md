Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.

O projeto está no SDK 54, não no mais recente (57) — rebaixado de propósito porque, em ago/2026,
a Apple está com uma fila de aprovação atrasada e a versão do Expo Go disponível na App Store
ainda está travada no SDK 54 (ver https://expo.dev/changelog/expo-go-and-app-store-may-2026).
Sem isso o app não abre no Expo Go em iOS. Não atualize pra uma SDK mais nova sem checar antes se
a Apple já liberou uma versão mais recente do Expo Go — senão o app volta a ficar incompatível.
